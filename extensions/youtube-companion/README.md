# TouchFish YouTube Companion

此扩展只控制摸鱼时钟创建的 YouTube 专属窗口。YouTube 与 Google 登录由你正常使用的 Chrome / Edge 完成；扩展不读取 Cookie、密码、账号信息或媒体下载地址。

1. 在已登录 YouTube 的 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`。
2. 开启「开发者模式」，选择「加载已解压的扩展程序」，选择当前整个 `youtube-companion` 文件夹。
3. 回到摸鱼时钟的 YouTube 面板，选择对应浏览器并点击「连接浏览器」。
4. 在仅本机可访问的配对页点击「连接此浏览器」。应用显示已连接后即可打开视频。

配对使用本机随机端口与每次启动更新的密钥，密钥只留在应用和扩展后台，不会附加到 YouTube 链接。浏览器重启或应用重启后，重新连接即可。

应用更新或扩展文件发生变化后，请在浏览器扩展管理页点击此扩展的「重新加载」，再回到应用连接。

播放／暂停和老板键只作用于专属窗口，不操作已有工作标签页。请不要把工作标签页拖入专属窗口；发现混合窗口时，扩展不会最小化整个工作窗口。断开应用连接时，扩展会尽量暂停、静音并收起受管窗口。
